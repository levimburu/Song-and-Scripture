# Song and Scripture: Features

Priority tags: **Core** = version 1, **Next** = soon after, **Later** = nice to have.

## 1. Display and output
- **Core:** Operator screen (control) plus clean audience screen (projector/TV) on a second display
- **Core:** Live "go live / clear / black / logo" buttons
- **Core:** Preview pane showing what's next before it goes live
- **Next:** Multiple outputs (main hall, overflow room, stage confidence monitor showing next lyric line)
- **Later:** Lower-thirds (speaker name, announcements) overlaid on video

## 2. Bible module
- **Core:** Multiple Bible versions, Swahili and English first (public-domain versions bundled)
- **Core:** Fast search by reference ("John 3:16") and by keyword
- **Core:** Show a single verse or a range, with auto-fit text sizing
- **Core:** Next/previous verse and chapter navigation by keyboard
- **Next:** Side-by-side parallel versions (e.g. English plus Swahili)
- **Next:** Import licensed versions the church owns
- **Later:** Verse history ("what was shown this service")

## 3. Songs and lyrics
- **Core:** Song library with add, edit, delete and search
- **Core:** Lyrics auto-split into slides (verse, chorus, bridge)
- **Core:** Jump to any section during a song
- **Core:** Paste or import lyrics (the church supplies its own, which avoids copyright problems)
- **Next:** Song arrangement ordering (verse, chorus, verse, chorus, bridge)
- **Next:** Import from text, Word or PowerPoint files
- **Later:** Chord sheets and key transposition for the band

## 4. Video and media
- **Core:** Play video and audio files on the audience screen
- **Core:** Background loops and still images behind lyrics and verses
- **Next:** Live camera input (HDMI capture or webcam) shown on screen
- **Next:** Streaming out to YouTube/Facebook (RTMP) with the overlays included
- **Later:** Countdown timers (service start, offering time)

## 5. Service planner (order of service)
- **Core:** Build a service playlist (song, verse, announcement, video, song)
- **Core:** Save, reuse and duplicate past services as templates
- **Next:** Drag-and-drop reordering during the service
- **Later:** Print or export the run sheet

## 6. Slides and announcements
- **Core:** Simple text slides (announcements, welcome, offering info)
- **Next:** Image slides and a basic PDF/PowerPoint import
- **Next:** Offering/M-Pesa details slide with a QR code

## 7. Design and themes
- **Core:** Themes for font, size, colour, background and text position/shadow
- **Core:** Different themes for songs and verses
- **Next:** Per-church branding (logo, colours)

## 8. Operation and reliability
- **Core:** Works fully offline
- **Core:** Runs smoothly on low-end Windows laptops
- **Core:** Autosave and crash recovery (the service queue must never be lost)
- **Next:** Remote control from a phone on the same Wi-Fi
- **Later:** Multi-operator roles (one person on lyrics, another on verses)

## 9. Business and product side
- **Core:** Licensing/activation that works offline (a key per church)
- **Next:** Backup and restore of the library
- **Later:** Optional cloud sync of songs and services across devices
- **Later:** Auto-update, plus a template/theme marketplace

## 10. Content to source
- Public-domain Bible versions in English and Swahili
- A starter pack of public-domain hymns (optional)
- Default backgrounds and themes (royalty-free)
